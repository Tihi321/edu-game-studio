# EGS-66 Pipeline notices music made by the asset tools, alt texts for every edition, stale job report

From the HUB-28 discoveries (hub `.claude/tickets/HUB-28-edu-mobile-music/discoveries.md`).

1. `steps.json` kept `music_plan:all` and `music_generate:all` as `skipped` after music was made through the asset tools (the run had music off, then `edu_media_settings` turned it on and `edu_music_plan` / `edu_asset_generate` made it). `Pipeline.musicFlow` now counts the music, sound effect and ambience assets that have a file in `assets.json`; when there are some, a skipped (or, with music off, an unfinished) music step becomes `done` with the note "N sound(s) made through the asset tools, not by the run". It happens on the next `edu_run_pipeline {slug}` (an advance).
2. A build failed with MISSING_TEXT `asset.mus-*.alt` / `asset.sfx-*.alt` in `en`: `mergeMedia` wrote the alt text to the source catalog only, and the editions made earlier (and the taught language) had none. `defaultAlts` (`media-link.ts`) gives every other catalog that exists the source text as a default where it has no alt text (the translator can replace it); `store.mergeMedia` saves those catalogs in the same write, so a relink after `edu_asset_generate` / `edu_asset_plan` / `edu_music_plan` leaves no gap.
3. The engine start requeued the old client job `deutsch-a1-pilot--summarize--all--r4`. That is by design: a job parked on a client model (Claude Code over MCP) stays in `running/`, its client task lived in memory, so at the start it goes back to `queued/` and is parked again (no model call, no cost). It was the last step (`summarize`) of run 4, the current run, so the handler ran. What was missing is a mention: `recoverRunning` now returns `old` (requeued jobs created more than 3 days ago) and the start log names them and says how to answer or remove them.

Tests: `tests/media-pipeline.test.ts` (music made by the tools after a run that skipped it: the steps are done), `tests/edu-editions.test.ts` (`defaultAlts`), `tests/scheduler.test.ts` (`recoverRunning` names the old requeued jobs).
